저장 및 전송
- 로그인/갱신 토큰은 서버 메모리에만 보관하며 파일, 브라우저 저장소, 로그에 기록하지 않습니다.
- 서버를 종료하면 다시 로그인해야 합니다. 정상 로그아웃은 갱신 세션 해지도 시도합니다.
- .local/registration.json에는 설치 식별자와 계정 등록 정보(클라이언트 ID, 검증된 계정 ID, 표시용 이메일/이름)만 저장합니다.
- .local 폴더는 복사/공유하거나 소스 저장소에 올리지 마세요. HTTP로 내려받을 수 없도록 차단했습니다.
- 다른 PC에서는 .local 없이 배포하여 별도의 설치 식별자를 생성해야 합니다.
- PDF 문맥 준비/복사는 로컬 동작입니다. 전송 버튼을 누르면 선택한 PDF 문맥, 포함한 이전 대화, 현재 질문이 OpenAI로 전송됩니다.
- 대화는 이 PC에 자동 저장됩니다. 재실행하면 최근 대화를 복원하며, PDF는 다시 열어 주세요.
- 기존 ChatGPT 대화나 메모리를 가져오거나 ChatGPT 대화 목록에 답변을 저장하는 기능은 없습니다.

제약
- 질문마다 선택한 PDF 범위와 이전 대화 범위를 보냅니다. 긴 문서가 입력 한도를 넘으면 전송 오류를 표시합니다.
- OCR, 문서 검색, 수식/표 복원은 아직 구현하지 않았습니다.
- 스캔, 표, 수식, 다단 편집은 텍스트 추출이 불완전할 수 있습니다.
- 구독 사용 연동은 OpenAI가 해당 계정과 모델에 제공하는 권한/한도에 따릅니다.

문맥 범위와 저장된 대화 (v0.5.0)
- PDF window: 선택 문장만 / 선택 페이지 / 앞뒤 1페이지(기본) / 앞뒤 2페이지 / 전체 문서. 여러 페이지에 걸친 선택도 지원합니다.
- 이전 대화 포함: 0 / 최근 3회(기본) / 6회 / 12회 / 전체. 완료된 질문과 답변만 사용합니다.
- PDF 본문은 이번 요청에 한 번 포함합니다. 과거 질문의 PDF 본문을 대화 기록에 누적하지 않습니다. 선택 문장, 과거 질문·답변은 요청마다 입력에 포함되며 무료 문맥을 보장하는 기능은 아닙니다.
- 앱의 질문·답변은 자동 저장합니다. '새 대화 · 문맥 비우기'는 기존 기록을 보관하고 새 문맥을 시작합니다. '대화 삭제'만 현재 저장 기록을 삭제합니다. 삭제 복구 기능은 없습니다.
- 저장된 대화 목록에서 이전 기록을 다시 엽니다. 같은 PDF를 열면 그 문서의 최근 대화가 연결됩니다.
- EXE 저장 위치: %APPDATA%\Paper Reader\conversations\. 개발 서버: paper-reader\.local\conversations\. EXE 위치나 포트가 바뀌어도 EXE의 저장 기록은 유지됩니다.
- PDF 원본이나 전체 추출 본문은 대화 파일에 저장하지 않습니다. 질문, 답변, 선택 문장, 페이지 정보는 PC에 일반 JSON 파일로 저장합니다. 대화 파일을 공유할 때 내용을 확인하세요.
- 응답 중에도 주기적으로 저장하며, 정상 종료 시 남은 저장을 마칩니다. 강제 종료나 전원 차단 시 마지막 수신 일부는 유실될 수 있습니다.
- ChatGPT 웹 모드는 앱에서 복사한 질문 기록만 저장합니다. 웹 답변은 가져올 수 없으며, 웹 대화 삭제와 앱 기록 삭제는 별개입니다.
- 연결 테스트와 중단된 응답도 보관하지만 다음 질문의 문맥에서 제외합니다.

화면 구성: PDF와 대화가 메인 공간을 사용하며 질문 입력란은 대화 아래에 있습니다. 인증, 모델 선택, 사용량 조회는 상단 환경 설정에 있습니다. 전송 내용을 먼저 보고 싶으면 입력란 아래의 전송 내용 미리보기 · 복사를 펼쳐 문맥과 질문 준비를 누르세요.

입력 토큰 표시: 질문과 선택 문맥을 수정하면 로컬에서 o200k_base 기준 추정치를 자동 계산합니다. 앱 요청 모드는 고정 지시문도 포함하며 실제 모델 인코딩·메시지 포맷 차이로 실제 값과 다를 수 있습니다. 웹 모드는 복사할 텍스트만 계산합니다. 토큰 계산은 외부 AI 요청을 보내지 않습니다. 실제 입력 토큰과 캐시 토큰은 API가 제공할 때만 답변 아래에 표시·저장합니다. 캐시 토큰은 전체 입력 토큰에 이미 포함되어 있습니다. 이 수치는 크레딧 차감액이나 계정 잔액이 아닙니다.

Auto (v0.6.0)
PDF 문맥 범위에서 Auto를 선택하세요. 선택 문장 없이 논문 전체에 질문할 수도 있습니다. PDF 전체를 로컬에서 검색해 최대 12개 후보를 만들고, 번역·문장 설명은 로컬 문맥을 사용합니다. 복합 질문은 전송 시 후보의 짧은 발췌를 에이전트에게 보내 문맥을 선택한 후 답변을 요청합니다. 입력 중에는 AI 요청이 없습니다.
Auto 예산 · 에이전트 선택을 펼치면 4천/8천/1만6천 답변 입력 예산을 고를 수 있습니다. 문맥 선택용 AI 입력은 별도이며 합계 추정치도 표시합니다. 미리 에이전트 선택을 실행하면 동일한 준비 내용의 전송에서 선택 요청을 중복하지 않습니다. 질문이나 범위를 수정하면 다시 선택합니다.
웹 모드는 로컬 Auto만 사용합니다. 선택 오류·시간초과·중지 시 답변을 자동 전송하지 않습니다. 필요하면 수동 문맥 범위로 전환하세요. 예산으로 발췌·제외된 페이지는 표시하며, 문맥 선택 이유와 페이지는 대화와 함께 저장됩니다.

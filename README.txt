Auto (v0.6.0)
PDF 문맥 범위에서 Auto를 선택하세요. 선택 문장 없이 논문 전체에 질문할 수도 있습니다. PDF 전체를 로컬에서 검색해 최대 12개 후보를 만들고, 번역·문장 설명은 로컬 문맥을 사용합니다. 복합 질문은 전송 시 후보의 짧은 발췌를 에이전트에게 보내 문맥을 선택한 후 답변을 요청합니다. 입력 중에는 AI 요청이 없습니다.
Auto 예산 · 에이전트 선택을 펼치면 4천/8천/1만6천 답변 입력 예산을 고를 수 있습니다. 문맥 선택용 AI 입력은 별도이며 합계 추정치도 표시합니다. 미리 에이전트 선택을 실행하면 동일한 준비 내용의 전송에서 선택 요청을 중복하지 않습니다. 질문이나 범위를 수정하면 다시 선택합니다.
웹 모드는 로컬 Auto만 사용합니다. 선택 오류·시간초과·중지 시 답변을 자동 전송하지 않습니다. 필요하면 수동 문맥 범위로 전환하세요. 예산으로 발췌·제외된 페이지는 표시하며, 문맥 선택 이유와 페이지는 대화와 함께 저장됩니다.

논문 읽기 노하우 (v0.7.1)
1. 첫 질문은 Auto로 논문의 큰 그림을 잡으세요. 예: “연구 질문, 핵심 결과, 가정과 실험을 구분하고 근거 페이지를 표시해 줘.” Auto가 고른 페이지와 제외한 페이지를 답변 전에 확인할 수 있습니다.
2. 특정 정리·수식은 PDF에서 해당 문장을 선택하고 '선택 페이지' 또는 '앞뒤 1페이지'로 좁히세요. 관련 내용이 다른 쪽에 있으면 '앞뒤 2페이지'를 쓰거나 해당 쪽을 직접 선택해 다시 질문하세요. Auto가 문맥 선택에 실패하면 앱은 답변을 전송하지 않으므로 수동 범위로 전환할 수 있습니다.
3. 후속 질문에는 설정된 수만큼의 완료된 질문·답변과 이번에 새로 선택한 PDF 부분이 들어갑니다. 과거 질문에 사용했던 PDF 본문 자체는 대화 기록으로 계속 누적되지 않습니다. 주제를 바꾸거나 기록이 길어지면 '새 대화'로 문맥을 비우세요. 기존 대화는 삭제하지 않는 한 남습니다.
4. 토큰을 아끼려면 처음부터 전체 문서를 보내지 말고 Auto 또는 좁은 수동 범위를 쓰세요. '전송 내용 미리보기 · 복사'에서 실제 포함 문맥을 확인할 수 있습니다. Auto의 선택용 AI 호출은 답변 호출과 별도이며, 입력 토큰 표시는 추정치입니다.
5. 답변의 페이지 표시는 원문과 대조하세요. 특히 정리의 가정, 수식의 부호·첨자, 표와 그림은 PDF 텍스트 추출이나 모델 해석에 오류가 있을 수 있습니다. “t=0에 대입해 검산해 줘”처럼 반례나 초기조건을 묻는 후속 질문이 유용합니다.
6. 답변과 저장된 질문에는 제목·목록·표·코드 및 LaTeX 수식(예: \(x^2\), \[a+b\])이 렌더링됩니다. 질문 입력창은 원문을 편집하는 곳이며 '질문 마크다운 미리보기'에서 표시 결과를 확인하세요. 입력한 마크다운 원문이 그대로 질문으로 전송됩니다.
7. 중요한 문장은 형광펜으로 표시하고, '주석 패널'의 마크다운 주석에 이해한 내용과 다시 확인할 점을 남기세요. 주석은 대화와 별도로 문서별 저장되며 PDF 원본을 바꾸지 않습니다.

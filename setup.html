02

논문 검색 · 노트 연결 선택 사항

Paper Reader Link를 연결하면 모델이 PDF 본문과 그림을 찾고 답변을 원문 노트에 저장할 수 있습니다.

기존 터널 ID와 Tunnels Read + Use 권한의 실행 키를 사용하세요. ChatGPT 작업 공간을 같은 터널에 연결해야 합니다.

OpenAI 터널 상세 화면의 tunnel_로 시작하는 ID를 복사하세요.

키는 Windows 계정 기준으로 암호화해 이 PC에 저장합니다.

실행 중에도 설정을 바꿀 수 있습니다. 새 연결을 확인한 뒤 저장하며 실패하면 기존 연결을 복원합니다. 터널 ID를 바꾸면 ChatGPT 플러그인에서도 같은 터널을 선택하세요. 연결 중지는 PDF 공유·노트·ChatGPT 로그인을 지우지 않습니다.

처음 연결하는 방법

터널 생성 → 실행 키 입력 → ChatGPT 플러그인 연결 순서입니다. 입력 중인 ID와 키는 설명을 열어도 유지됩니다.

1. 터널을 만들고 ID 복사

  1. OpenAI 터널 설정을 열고 사용할 Platform 조직을 선택합니다.
  2. 새 터널을 만들거나 기존 터널을 엽니다. 사용할 ChatGPT 워크스페이스를 연결합니다.
  3. 터널 상세의 tunnel_… ID를 복사해 이 앱의 Tunnel ID에 붙여넣습니다.

생성에는 Tunnels Read + Manage 권한이 필요합니다. 설정이 보이지 않으면 해당 조직 관리자에게 권한을 요청하세요.

2. 실행 키 발급과 권한 확인

  1. OpenAI API 키 관리에서 실행용 키를 준비합니다. 터널과 같은 조직에서 사용할 수 있는 키여야 합니다.
  2. 실행 주체와 키에 Tunnels Read + Use 권한이 있는지 확인합니다. 권한 설정이 보이지 않으면 조직 관리자에게 터널 실행용 키와 권한을 요청하세요.
  3. 발급받은 키를 이 앱의 Runtime API key 입력란에 붙여넣고 키 저장하고 Link 시작을 누릅니다.

ChatGPT 웹 로그인과 별도입니다. 기존 키를 이미 저장했다면 다시 발급할 필요가 없습니다. 키는 채팅에 보내지 마세요.

3. ChatGPT에 같은 터널 연결

  1. Link가 실행 중인 상태에서 ChatGPT 플러그인 페이지를 엽니다.
  2. + → Add custom MCP server에서 이름을 Paper Reader Link로 입력하고, Connection을 Tunnel로 선택합니다.
  3. 위에서 만든 같은 터널을 선택합니다. 이 앱의 로컬 서버 인증은 No authentication으로 선택하고, 내용을 검토한 뒤 플러그인을 생성·설치합니다.

터널이 목록에 없으면 연결한 ChatGPT 워크스페이스와 조직 권한을 확인하세요. 워크스페이스 정책에 따라 관리자의 허용이 필요할 수 있습니다.

4. 실제 도구 호출로 확인

ChatGPT 대화에서 Paper Reader Link를 선택하고 “Paper Reader Link를 열어줘”라고 요청합니다. PDF에서 질문을 보낸 뒤 본문 검색·이미지 확인이 표시되는지 확인하세요. 터널 실행 표시만으로 설정 완료를 판단하지 않습니다.

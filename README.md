# Agentic PDF Reader

PDF.js 기반 Windows PDF 리더입니다. ChatGPT 대화를 기본 흐름으로 삼아, PDF 선택 → 질문 → 원문 노트 저장을 한 화면에서 이어갑니다. 앱에서 직접 요청하는 방식은 환경 설정의 보조 옵션입니다.

현재 개발 버전은 **0.12.0**입니다. [개발 인수인계](docs/DEVELOPMENT-HANDOFF.md)에 실행·빌드·터널 설정과 NTK 검증 결과를 정리했습니다. ChatGPT Link에서 PDF 전체 검색, MCP 페이지 이미지, 기존 주석·논문 노트 읽기를 사용할 수 있습니다. Link로 저장한 답변은 질문 기록에도 완료로 반영되며, 유휴 검색·렌더링 자원은 30초 후 회수하고 다음 요청에서 같은 고정본으로 복구합니다. 읽기 상태 복원 중 새로 입력한 질문을 유지하며, 연결 오류 시 다른 온라인 PDF로 대신 답하지 않도록 요청합니다.

## Windows 설치

0.12.0은 **문단 검색 → 짧은 원문 읽기 → 부족한 앞뒤 문맥만 확장**을 기본으로 사용합니다. 검색은 기본 3개의 짧은 발췌, 읽기는 기본 1,600자/최대 4,000자입니다. 커서로 잘린 문단의 나머지나 인접 문단을 읽고, 충분하면 멈춥니다. 기존 `read_pdf(pages)`도 이제 첫 문단만 반환합니다. ChatGPT 플러그인의 도구를 새로 고침하세요. [확장 규칙과 호환성](docs/PARAGRAPH-CONTEXT.md). 과거 ChatGPT 도구 결과를 삭제하는 기능은 아닙니다.

0.11.5는 공유한 PDF의 **기존 주석·논문 노트 읽기**를 추가합니다. AI가 저장한 답변과 사용자가 작성한 노트를 함께 검색하고 원문 발췌·페이지와 함께 읽습니다. 앱 업데이트 후 ChatGPT의 **Paper Reader Link → 관리 → 도구 새로 고침**에서 `list_annotations`, `read_annotation`이 보이는지 확인하세요. “기존 논문 노트도 참고해서 설명해줘”라고 질문하면 됩니다. **답변을 논문 노트에 저장**을 꺼도 기존 노트는 읽을 수 있습니다. 기존 데이터에 작성자 구분은 없으며, PDF 파일 자체에 삽입된 외부 주석 추출은 지원하지 않습니다.

0.11.4에서는 질문창 옆의 **답변을 논문 노트에 저장**을 체크할 때만 주석·노트 저장을 요청합니다. 기본은 해제이며, 선택한 상태는 이 PC에 저장됩니다. 기존 자동 허용 설정은 새 체크박스에 적용하지 않습니다.

0.11.3은 ChatGPT 입력창의 플러그인 칩을 작성 중인 질문으로 오인하던 문제를 수정합니다. 플러그인을 유지하고 실제 초안만 보호하며, 전송된 메시지를 확인할 때도 칩을 구별합니다. 터널 설정 파일의 Windows 프로필 경로 오류도 수정했습니다. 실제 Chromium 검증은 `npx electron scripts/web-send-dom-check.mjs`로 실행합니다.

실제 화면을 포함한 [설치·사용설명서 PDF](output/pdf/Agentic-PDF-Reader-0.11.1-설치-사용설명서.pdf)에서 설치, 인증, 질문, 노트, 질문 기록과 오류 복구 순서를 확인할 수 있습니다.

`Agentic-PDF-Reader-0.12.0-install.exe`를 실행합니다. Node.js, npm, 별도 터널 실행기는 필요하지 않습니다. 설치 프로그램은 사용자 계정 범위에 설치하고 바탕 화면·시작 메뉴 바로가기를 만듭니다.

- **지금 인증 설정:** 설치 후 앱의 연결 화면을 엽니다. ChatGPT 로그인은 오른쪽 웹 화면에서 직접 진행합니다. 논문 전체 검색·이미지 확인·노트 저장을 쓰려면 터널 ID와 실행 키 및 ChatGPT 플러그인 연결도 설정합니다.
- **나중에 설정:** 인증 입력 없이 설치를 마치고 PDF와 노트를 사용합니다. **환경 설정 → 인증·Link 설정 열기**에서 다시 연결할 수 있습니다.

설정한 실행 키는 이 Windows 계정의 DPAPI로 암호화합니다. 기존 ChatGPT 프로필 `%APPDATA%\Paper Reader`와 Link 인증 `%LOCALAPPDATA%\PaperReaderLink`를 재사용하며, 계정 정보·키·개인 PDF를 설치 파일에 넣지 않습니다. 업데이트나 제거 시 사용자 데이터를 삭제하지 않습니다. 터널 프로세스가 실행됐다는 표시와 실제 ChatGPT 플러그인 연결은 구별합니다. 상세 내용은 [설치와 인증 안내](docs/WINDOWS-INSTALLER.md)를 참고하세요.

## 기능

- 선택 문장 또는 현재 페이지에 쉽게 설명·번역·수식 풀이 질문 준비
- 집중 읽기(F8)로 PDF 확대, 논문 노트를 옆에 두고 수식·표 대조
- 논문 노트의 원문·답변 검색, 정확한 원문 위치 이동, 전체 노트 Markdown 내보내기
- 논문 노트와 편집 미리보기는 Paper Reader의 서체·잉크색·구분선·모서리 테마를 공유합니다. 본문은 14px로 표시하며 긴 수식과 표는 노트 안에서 스크롤합니다.
- 페이지 PNG 저장: 수식·그림을 ChatGPT에 직접 첨부할 고해상도 이미지 준비
- PDF 문장 선택 후 질문, 이전 대화 포함 범위 선택
- PDF 옆 별도 패널의 형광펜 및 마크다운 주석, 문서별 자동 저장
- 수동 문맥 범위 및 Auto 문맥 선택, 입력 토큰 추정치 표시
- 대화 자동 저장, 새 대화 시작 및 명시적 삭제
- 질문과 답변의 마크다운 및 수식 표시, 질문 입력 미리보기
- ChatGPT 웹에 질문 복사 또는 로그인 후 앱에서 직접 요청
- Windows 앱의 PDF 옆 ChatGPT 웹 패널: 웹 대화 유지, 앱 기록 전환, 새로고침·브라우저 이어 열기
- Windows 앱에서는 **ChatGPT에 질문 보내기**로 선택 문장과 질문을 오른쪽의 현재 대화에 전송합니다. Link 선택 ID와 주석 저장 요청도 함께 전달합니다. 로그인 완료 후 빈 입력창에서 사용하며, 작성 중인 초안이나 생성 중인 답변이 있으면 전송을 멈춥니다.
- 웹 로그인은 앱 전용 세션에 보관됩니다. 웹 입력창 구조가 바뀌거나 전송을 확인하지 못하면 오른쪽 대화를 확인하고 ‘질문 복사’를 사용하세요. 브라우저 실행에서는 ‘질문 복사’ 후 ChatGPT에 붙여넣습니다.
- 현재 ChatGPT의 ‘보내기’ 버튼과 입력 폼의 활성 전송 버튼을 지원합니다. 자동 전송 실패 시 버튼 탐지·비활성화·입력 내용 변경을 구분해 안내합니다.
- 문장 선택 없이 현재 페이지도 같은 버튼으로 질문합니다. 페이지 답변은 상단 노트 아이콘에 연결되고, 문장 답변은 선택 위치에 연결됩니다. 노트는 이 PC에 저장되며 원본 PDF 파일은 수정하지 않습니다.
- 읽던 페이지·배율·회전·질문 초안을 PDF별로 보관합니다. 같은 PDF를 다시 열면 복원되며, EXE 업데이트나 localhost 포트 변경에도 유지됩니다. 질문 도구는 초안만 만들고 Ctrl+Enter로 전송합니다.
- PDF.js의 별도 편집 버튼을 정리하고 앱의 ‘하이라이트 저장’·‘노트 추가’로 통일했습니다. 노트 패널은 오른쪽 대화 공간에 열리며 PDF 본문을 그대로 볼 수 있습니다.
- EXE 업데이트 시에도 `%APPDATA%\Paper Reader`의 같은 웹 로그인 프로필을 사용합니다. 앱 버전으로 웹 브라우저 식별 정보가 바뀌지 않게 하고, 웹 로딩 완료와 정상 종료 시 쿠키 저장을 완료합니다. 서비스에서 세션을 만료하거나 직접 로그아웃하면 다시 로그인해야 합니다.
- 모드에 맞는 상단 계정 안내, 보조 모드의 Codex 사용량 조회 및 외부 CSS 테마 지원
- PDF 본문 주석 강조와 아이콘 클릭으로 연결된 주석 확인
- ChatGPT가 실제 읽은 본문·이미지 페이지를 답변 노트와 함께 보관하고, 노트의 페이지 버튼으로 원문에 이동합니다. 노트 편집·앱 재실행·Markdown 내보내기에도 근거 기록이 유지됩니다. 검색에 걸린 페이지만으로 인용 정확성을 보장하지 않습니다.
- Link 중복 실행은 기존 터널·키 설정을 변경하지 않고 안내합니다. PDF 이미지 처리기가 중단되면 고정된 원본으로 복구합니다. PDF 전체 검색과 노트 저장 허용 설정은 실행 포트가 바뀌어도 유지됩니다.
- **Paper Reader Link 시제품**: 질문 당시 PDF를 고정해 SQL로 근거 페이지를 찾고 실제 페이지 PNG를 ChatGPT MCP 도구로 읽습니다. 답변은 원래 PDF 위치에 주석으로 저장할 수 있습니다. [한국어 연결 안내](Paper-Reader-Link-연결안내.md)를 참고하세요. 실제 ChatGPT 사용에는 별도 Secure MCP Tunnel/사용자 지정 MCP 등록이 필요합니다.

앱 내 요청은 계정에 제공된 Codex / ChatGPT Work 공유 사용량 또는 허용된 추가 크레딧을 사용할 수 있습니다. 일반 ChatGPT 대화 전용 한도로 처리된다고 보장하지 않습니다. Auto의 문맥 선택 요청은 답변 요청과 별도입니다.

## 다음 개발과 안정성 검증

[안정성 테스트와 발전 방향](docs/QUALITY-AND-ROADMAP.md)에 우선순위, 재현 시나리오, 완료 기준을 정리했습니다. 현재 구현과 아직 실행하지 않은 계획을 구별합니다.

1. **안정화:** 재인증 없는 재연결, 문서 전환 중 질문·노트 일치, 중복 전송 방지, 좌표 정확성, 장애 후 복구를 실제 EXE에서 검증합니다. 새 검색 기능과 내장 ChatGPT 전송·노트 저장을 합친 전체 흐름이 우선입니다.
2. **근거 이동:** 답변·노트의 근거에서 정확한 PDF 문장·수식·그림 위치로 이동하고 돌아옵니다.
3. **영역 질문:** 그림·수식을 직접 선택하고 텍스트와 PNG를 함께 활용합니다. 현재 MCP 페이지·영역 PNG 반환은 구현됐으며 PDF 위 드래그 선택 UI는 향후 작업입니다.
4. **읽기 재개와 비교:** 논문별 미해결 질문·노트를 다시 찾는 경험부터 개선하고, 문서별 출처가 유지되는 여러 논문 비교로 확장합니다.

ChatGPT를 기본 흐름으로 유지합니다. 앱 내 요청은 Plan B로 두며, OCR·문단 검색·추가 검색 모델은 실제 실패 사례와 품질·시간·비용 평가를 바탕으로 도입합니다.

## 개발 실행

Node.js 22 이상이 필요합니다.

`npm test`는 데스크톱 앱과 같은 Electron 내장 Node/SQLite 런타임으로 실행합니다. 일반 Node 22에 없는 FTS5/authorizer 기능도 이 경로에서 검증합니다.

```powershell
npm ci
npm start
```

브라우저에서 http://127.0.0.1:8767 을 엽니다. 데스크톱 창은 `npm run desktop`으로 실행합니다.

```powershell
npm test
npm run build
npm run build:installer
```

`npm run build`는 Windows x64 portable EXE, `npm run build:installer`는 NSIS 설치 EXE를 빌드합니다. 설치 파일은 `release/installer/Agentic-PDF-Reader-<version>-install.exe`에 생성됩니다. 빌드는 공식 OpenAI tunnel-client v0.0.16과 해시를 확인하고 MCP SDK 번들을 포함합니다. 개발자 PC에 검증된 바이너리가 없으면 공식 배포에서 다운로드합니다. EXE 배포 파일은 소스 Git 저장소에 포함하지 않습니다.

## 데이터와 설정

개발 실행 데이터는 `.local/`, EXE 실행 데이터는 `%APPDATA%\Paper Reader`에 저장합니다. 로그인 토큰은 서버 메모리에 보관합니다. `.local/`의 등록 정보, 설정, 대화와 주석 기록을 저장소에 커밋하지 마세요.

기본 테마는 `app.css`, 기능별 스타일은 `ui.css`입니다. EXE 옆의 `Paper-Reader.css`로 테마를 덮어쓸 수 있습니다.

자세한 사용법과 제한 사항은 [README.txt](README.txt)를 참고하세요.

## 포함된 구성 요소

PDF.js 6.4.299 배포본을 `pdfjs/`에 포함합니다. 해당 구성 요소의 라이선스는 [pdfjs/LICENSE](pdfjs/LICENSE)에 있습니다. 마크다운 표시는 Markdown-it, 수식 표시는 KaTeX와 @mdit/plugin-katex를 사용합니다. 라이선스는 `vendor/licenses/`에 있습니다. 렌더링 시 원시 HTML과 원격 이미지 로딩을 허용하지 않습니다.
